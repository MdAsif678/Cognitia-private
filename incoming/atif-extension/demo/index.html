Hackathon Acceptance Criteria Verification
A. Claim Rewards Flow
DApp ➔ Interceptor ➔ Backend Analysis ➔ Side Panel Risk Report ➔ Continue ➔ MetaMask.
B. Reject Behavior
User clicks Reject in Side Panel ➔ DApp receives EIP-1193 Error 4001 ➔ MetaMask never opens.
C. Continue Behavior
User clicks Continue ➔ Request forwarded once ➔ MetaMask opens exactly once.
D. Account Change Invalidation
Switching account while report is pending immediately marks the report STALE.
E. Chain Change Invalidation
Switching network chain while report is pending marks the report STALE.
F. Analysis Unavailable Safety
When backend is down or times out, UI shows "Analysis unavailable" with no green indicators.
G. eth_call Passthrough
Calling eth_call immediately delegates to provider without triggering interception.

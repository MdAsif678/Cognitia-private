Install

Add Cognitia to your browser.

Works in Chrome, Edge, Brave and other Chromium browsers (version 116 or newer). It takes about a minute.

  1. Unzip the download

    Extract cognitia-extension.zip to a folder you will keep, for example Documents/cognitia-extension. The browser loads it from there, so don't delete it.

  2. Open the extensions page

    Go to chrome://extensions (Edge: edge://extensions, Brave: brave://extensions).

  3. Turn on Developer mode

    Use the switch in the top-right corner of the page (bottom-left in Edge). New buttons appear.

  4. Load unpacked

    Click Load unpacked and choose the unzipped folder, the one that contains manifest.json. Pin Cognitia from the puzzle-piece menu so its badge is visible.

  5. Reload open tabs

    Pages opened before the install are not protected until you reload them. Then open the live demo and try an offer.

Using it

What you'll see.

  • When a site asks your wallet to sign, the Cognitia side panel opens with the report. If the browser blocks it, click the Cognitia icon (it shows a ! badge while a request is held).
  • Reject tells the site you declined. Continue to wallet opens your wallet with the exact payload that was reviewed.
  • If analysis is unavailable you can still continue, but only after an explicit acknowledgement.
  • For the demo, use a fresh test wallet with Sepolia test ETH, never a wallet holding real funds.
